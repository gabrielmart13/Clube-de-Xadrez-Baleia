# Clube de Xadrez Baleia

O Clube de Xadrez Baleia é um projeto que tem como objetivo promover o ensino e a prática do xadrez entre os integrantes do Grupo Escoteiro do Baleia. A plataforma será desenvolvida para auxiliar na organização das atividades do clube, permitindo o gerenciamento de alunos, turmas, inscrições, eventos e partidas, além de disponibilizar informações sobre o desempenho e o ranking dos participantes.

O sistema contará com uma área para administradores, responsável pelo gerenciamento das atividades e pelo registro dos resultados das partidas, e uma área para alunos, na qual poderão acompanhar seu desempenho, consultar eventos, realizar inscrições e visualizar o ranking. Dessa forma, o projeto busca facilitar a administração do clube, incentivar a participação dos escoteiros e promover o desenvolvimento do raciocínio lógico e estratégico por meio do xadrez.
